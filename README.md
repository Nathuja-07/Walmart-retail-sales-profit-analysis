Walmart Retail Sales Analysis

Project Overview

This project focuses on analyzing Walmart retail sales data to understand sales performance, profitability, customer reach, and product performance through an interactive Power BI dashboard.

Business Objective

- Analyze overall sales and profit performance.
- Identify top-performing products and categories.
- Understand sales distribution across states.
- Monitor key business performance indicators.
- Provide insights to support business decision-making.

Tools & Technologies

- Microsoft Excel: Data cleaning and preprocessing.
- Microsoft Power BI: Data visualization, dashboard development, and reporting.

Project Workflow

1. Imported the Walmart retail sales dataset.
2. Cleaned and prepared the data using Excel.
3. Loaded the cleaned dataset into Power BI.
4. Created KPI cards and interactive visualizations.
5. Analyzed sales, profit, products, and geographical performance.

Dashboard Preview

Dashboard screenshots are available in this repository.

Key Analysis Areas

- Overall Sales Performance
- Profit and Loss Analysis
- Top 10 Products
- Product Category Performance
- State-wise Sales Analysis
- Customer and Order Overview

Business Value

The analysis helps identify sales trends, profitable products, and geographical performance to support better retail business decisions.
